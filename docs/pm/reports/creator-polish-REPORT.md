## What was built (in play)

### Two bugs that stopped a character from being created (root causes found, not patched around)
1. **Granted cantrip dropped (Aasimar's Light).** `toClientShape` in `speciesService.js` sent each *variant's* `innateSpells` to the creator but not the *species-level* ones. Aasimar (Light), Tiefling (Thaumaturgy, Hellish Rebuke, Darkness) and Firbolg (Detect Magic, Disguise Self) therefore never had their granted spells in the creator's final cantrip list, and the server refused the commit with "must include the granted cantrip 'Light' (species)". **Evidence:** Zach's saved draft (a copy of `local.db`, test data) holds an Aasimar Cleric whose `known_cantrips` were spare the dying, sacred flame, word of radiance, with no light. Now `toClientShape` carries `innateSpells`.
2. **Home Region picker never rendered (Folk Hero, Hermit).** Both themes serve no fixed option list (`creation_choice_options: null`) and rely on the origin's regions. With a Forgotten Realms origin the creator produced no options, so Stage 3 drew no picker, while the server still required a non-empty pick: "theme 'Folk Hero' requires a Home Region at Review". Now a theme that serves no list gets the origin's region list (46 for the Realms); themes with their own list (City Watch, Urchin: 10 cities) are unchanged. Review now also requires the pick whenever Stage 3 offers one.
3. **Blank screen** when a Human picks Magic Initiate as the Versatile origin feat: Stage 1 called `prettify()` and never defined it (every other stage has its own). It has been that way since the first commit. A scan of all six stages and the shell found no other undefined function calls.

### Readability and layout
- **One CSS rule set** in `creator-theme.css`, scoped to the creator: checkboxes and radios no longer stretch to full width (this was pushing every label to the far right, on the cantrip, spell, Versatile and Stage 5 equipment pickers), labels no longer inherit the global orange, and the text tokens are darker (`--ink-2` `#4a4a4f`→`#26262b`, `--ink-3` `#86868b`→`#4b4b52`, `--ink` `#18181a`→`#0e0e10`). Other screens are unchanged.
- **Spell pickers** (Stage 2 cantrips; Stage 4 known, spellbook, prepared): one shared row. Checkbox, spell name, the **full** description, then a facts line built only from catalog fields (cast time, range, duration, saving throw, ritual). No tooltip on these rows. A counter says how many picks are left, and unpicked rows gray out and disable at the limit.
- **"Character limit" Zach saw was mine:** an earlier version of the picker cut descriptions at 170 characters (that is why Resistance ended "reduced by…"). Removed; descriptions show in full.
- **Spell descriptions cleaned** (`server/data/spellCatalogData.js`, client copy regenerated): 57 descriptions lost ruleset/version talk ("Reworked in 2024", "in the 2024 version", "buffed in 2024", "Absorbed into the PHB in 2024" and similar), mechanics kept as written. Three internal developer notes were cut (banishing smite, give life, weakening aura). Guidance and Resistance were rewritten to say what they do. A test now fails if any description names a ruleset year, edition or a developer note.
- **Stage 5 gold:** now reads, for example, "Your class starts with 110 GP. Your Folk Hero background changes that by 0% (no change). People with this background set out with exactly what the class normally gets… You would start with 110 GP." It shows the percentage, the GP change and a plain reason (reasons follow the groupings already documented in `themeGoldModifiers.js`).
- **Feat-granted picks** (Stage 4): the empty message now says "Your feats do not grant any skill, tool, or language proficiencies" when feats are picked but grant none (Zach's Tough + ancestry feat grant none), and the "once you pick…" message only before they are picked.
- **Review screen:** starting equipment lists the actual items (with the chosen holy symbol), not raw pick JSON; Light Bearer (and any "You know the X cantrip" trait) shows the cantrip's description; the ability method reads "Standard Array" not `standard_array`; the "Choice" column appears only when a species choice exists (renamed "Your pick"); the internal languages note, the server-internals note and the "no feat line" ruleset note are removed.
